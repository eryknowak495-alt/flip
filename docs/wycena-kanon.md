## Koszty i net
- **Koszty transakcyjne:** ~40 zł (wysyłki + drobne).
- **Net ≈ exit − buy − 40 zł.**
- **Allegro Lokalnie / KT:** odejmij dodatkowo **~4,9% od exit** (prowizja).
- Net podawaj jako **widełki pes.–opt.**: pes. = dolny exit − buy − 40; opt. = górny exit − buy − 40.

## HARD-STOP — ODRZUĆ natychmiast
- iCloud / blokada aktywacji (Find My / Activation Lock).
- MDM (zarządzanie firmowe).
- SIM lock (blokada operatora).
- Face ID / Touch ID martwy.
- OLED spękany / plamy / wypalenia dyskwalifikujące.
- Opis „na części" / „uszkodzony".
